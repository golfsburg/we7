📋 Einrichtungsanleitung
1 Supabase-Projekt erstellen

Gehe zu supabase.com/dashboard, klicke auf New Project und wähle einen Namen wie pv-tracker. Region: eu-central-1 (Frankfurt) für beste Latenz aus Österreich.

2 Tabelle anlegen (SQL Editor)

Im Supabase Dashboard → SQL Editor → diesen Code ausführen:

create table if not exists pv_entries ( id text primary key, type text not null, date date not null, kwh numeric not null, peak numeric, hours numeric, self_kwh numeric, feed_kwh numeric, weather text, temp numeric, note text, created_at timestamptz default now(), updated_at timestamptz default now() ); -- Row Level Security aktivieren (empfohlen) alter table pv_entries enable row level security; -- Öffentlichen Lese-/Schreibzugriff erlauben (für anon key) create policy "allow_all" on pv_entries for all using (true) with check (true);
3 API-Zugangsdaten holen

Dashboard → Project Settings → API
Kopiere: Project URL und anon / publishable key
→ Oben in die Felder einfügen und auf Verbinden klicken.

4 Daten hochladen

Nach erfolgreicher Verbindung: ↑ Lokal → Supabase hochladen klicken.
Alle lokalen Einträge werden in die Cloud synchronisiert.
Mit ⇄ Merge werden Cloud- und Lokaldaten zusammengeführt (kein Datenverlust).
